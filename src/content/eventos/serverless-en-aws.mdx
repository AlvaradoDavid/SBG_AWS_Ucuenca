Hernán es AWS Community Builder, lidera el AWS User Group Quito y tiene dos
certificaciones de AWS. Armó la charla alrededor de los tres servicios que forman
el backend serverless más común: [AWS Lambda](/servicios/computo/lambda/) ejecuta
el código solo cuando llega una petición,
[Amazon API Gateway](/servicios/integracion-y-mensajeria/api-gateway/) expone los
endpoints y [Amazon DynamoDB](/servicios/bases-de-datos/dynamodb/) guarda los
datos en una base NoSQL que administra AWS.

Después vino el demo en vivo. Hernán construyó desde cero un backend funcional,
de la idea en una máquina local a la API desplegada en la nube, sin salir de la
capa gratuita de AWS. De ahí el lema: desplegar como senior con las herramientas
que hoy pide el mercado laboral, sin pagar como senior.

Se conectaron 51 personas, que hicieron muchas preguntas.
