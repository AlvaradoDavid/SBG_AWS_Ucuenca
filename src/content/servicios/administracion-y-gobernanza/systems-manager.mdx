## Descripción

Session Manager abre una sesión en una instancia sin puertos abiertos ni llaves SSH, con todo registrado; Patch Manager aplica actualizaciones en ventanas programadas; Run Command ejecuta lo mismo en cien máquinas; y Parameter Store guarda configuración y secretos con cifrado.

Parameter Store merece atención propia: es la forma gratuita de sacar credenciales del código, y la puerta de entrada a Secrets Manager cuando hace falta rotación automática.
