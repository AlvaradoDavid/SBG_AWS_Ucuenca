## Descripción

El gateway se instala como máquina virtual en el centro de datos y guarda en caché los datos usados con más frecuencia mientras respalda todo contra S3, Glacier o EBS. Para las aplicaciones locales no cambia nada: siguen viendo un recurso compartido de red.

El modo de cinta virtual es el más adoptado, porque permite jubilar bibliotecas de cintas físicas sin cambiar el software de respaldo.
