## Descripción

Data Pipeline define flujos con dependencias, reintentos y programación para copiar y transformar datos entre S3, RDS, DynamoDB y EMR. Fue durante años la herramienta estándar de extracción y carga en AWS.

Aparece aquí por completitud del catálogo y porque todavía se encuentra en arquitecturas antiguas.

**Nota:** AWS ya no acepta clientes nuevos en este servicio. Para canalizaciones nuevas, la ruta recomendada es AWS Glue, Step Functions o MWAA.
