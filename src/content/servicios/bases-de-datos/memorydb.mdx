## Descripción

La diferencia con ElastiCache es exactamente esa: ElastiCache es una caché, y si se pierde, se repuebla desde la base de datos real. MemoryDB escribe cada cambio en un registro de transacciones distribuido antes de confirmarlo, así que sirve como base de datos principal.

El precio es notablemente más alto que el de una caché; se justifica solo cuando la durabilidad es un requisito.
