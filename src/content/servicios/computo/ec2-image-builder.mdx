## Descripción

Image Builder define una receta — una imagen base más una lista de componentes de instalación y validación — y ejecuta el proceso en un canal automatizado que construye la AMI, la prueba y la comparte con las cuentas y regiones que indiques.

Resuelve el problema de la imagen dorada desactualizada: en vez de un documento con pasos manuales, la imagen se reconstruye sola cada vez que sale un parche.
