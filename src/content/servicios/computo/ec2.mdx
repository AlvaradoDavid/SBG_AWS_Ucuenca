## Descripción

Amazon EC2 es el servicio de cómputo más fundamental de AWS: te da una máquina virtual — una
*instancia* — sobre la que tienes el mismo control que tendrías sobre un servidor físico propio.
Eliges el sistema operativo, el tamaño de CPU y RAM, el almacenamiento adjunto, y qué corre en ella.

A diferencia de servicios serverless como Lambda, la instancia sigue encendida (y cobrando) mientras
tú no la apagues. Ese es a la vez su mayor ventaja — control total y disponibilidad continua — y su
mayor riesgo para quien trabaja con créditos limitados.

## Cómo funciona

1. Eliges una **AMI** (por ejemplo, Amazon Linux 2023 o Ubuntu).
2. Eliges un **tipo de instancia** que define CPU y memoria.
3. La instancia arranca dentro de una **VPC** (tu red privada en AWS), con un **security group**
   que decide qué puertos están abiertos.
4. Te conectas por SSH usando tu **key pair** y la administras como cualquier servidor Linux.

## Manos a la obra

El laboratorio mínimo para entender EC2 en una sesión de club:

- Lanza una instancia `t3.micro` con Amazon Linux 2023 y un security group que solo abra el puerto 22.
- Conéctate por SSH e instala un servidor web (`sudo dnf install -y nginx && sudo systemctl start nginx`).
- Abre el puerto 80 en el security group y visita la IP pública desde el navegador.
- **Termina la instancia al terminar** — este último paso es el que más se olvida.
