## Descripción

Lightsail existe porque la primera experiencia con EC2 puede ser abrumadora: hay que elegir tipo de
instancia, VPC, subred, grupo de seguridad, volumen y modelo de compra antes de ver una página web
funcionando. Lightsail comprime todo eso en una decisión — qué plan mensual — y una imagen de partida.

El precio fijo es la característica que más importa a un club universitario con créditos limitados.
Con EC2 hay que vigilar la factura; con Lightsail, el costo del mes se conoce el día que se crea la
instancia. A cambio se pierde flexibilidad: menos tipos de máquina y menos integración fina.

## Cómo funciona

1. Eliges un **plano**: solo el sistema operativo, o una pila ya instalada como WordPress o LAMP.
2. Eliges el **plan mensual**, que fija CPU, memoria, disco SSD y transferencia incluida.
3. Lightsail crea la instancia con su red ya configurada y te da acceso por SSH desde el navegador.
4. Asocias una **IP estática** y, si quieres, apuntas tu dominio con el DNS del propio servicio.
5. Programas **instantáneas** para poder restaurar o clonar la instancia cuando haga falta.

## Manos a la obra

- Crea una instancia con el plano de WordPress en el plan más pequeño disponible.
- Asocia una IP estática y entra por el cliente SSH del navegador, sin configurar llaves.
- Publica una entrada y comprueba que responde desde la IP.
- Toma una instantánea manual y restáurala como instancia nueva para ver el mecanismo.
- **Borra las dos instancias, las instantáneas y libera la IP estática** al terminar la práctica.
