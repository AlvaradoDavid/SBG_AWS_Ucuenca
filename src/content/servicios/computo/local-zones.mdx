## Descripción

Una Local Zone es un trozo de una región de AWS colocado en un área metropolitana concreta. Se ve como una zona de disponibilidad más dentro de tu VPC, así que lanzas instancias EC2 allí con las mismas API de siempre, pero el tráfico recorre mucha menos distancia.

No todos los servicios están disponibles en cada Local Zone: se usan como extensión de latencia, con la región principal como base.
