## Descripción

El repositorio guarda aplicaciones empaquetadas con AWS SAM: plantillas que declaran funciones Lambda, tablas, colas y permisos. Al desplegar una, se copia a tu cuenta como un stack de CloudFormation que puedes leer y modificar.

Para un club es útil como material de lectura: son ejemplos completos de arquitectura serverless con permisos ya declarados.
