## Descripción

Amplify conecta con el repositorio, compila en cada push y publica el sitio en una CDN con HTTPS y dominio propio. Sus bibliotecas añaden autenticación con Cognito, API con AppSync y almacenamiento en S3 desde el código del cliente.

Es el camino más corto entre un proyecto de React o Astro y un sitio en producción sobre AWS.
