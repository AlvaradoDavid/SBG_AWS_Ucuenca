## Descripción

AppSync expone un esquema de GraphQL y resuelve cada campo contra DynamoDB, Lambda, Aurora o una API HTTP. Las suscripciones sobre WebSocket entregan los cambios al instante a todos los clientes conectados.

Es la alternativa a API Gateway cuando el problema es que las pantallas necesitan formas distintas de los mismos datos.
