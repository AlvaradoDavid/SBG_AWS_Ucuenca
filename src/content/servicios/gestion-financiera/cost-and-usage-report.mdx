## Descripción

El informe deja en S3 los datos crudos de consumo, que se consultan con Athena o se cargan en QuickSight. Es la fuente autorizada para cualquier análisis de costos serio, incluidos los descuentos aplicados y la amortización de las reservas.

Cost Explorer responde preguntas frecuentes; este informe permite responder cualquiera.
