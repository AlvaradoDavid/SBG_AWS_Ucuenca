## Descripción

Se arrastran funciones, colas, tablas y API sobre un lienzo, se conectan, y la herramienta escribe la plantilla de AWS SAM correspondiente, incluidos los permisos entre componentes. El dibujo y el código quedan sincronizados en ambos sentidos.

Es útil para enseñar: la arquitectura se ve, y el archivo resultante es el mismo que se desplegaría a mano.
