## Descripción

Cada servicio de AWS tiene su propia API con nombres y parámetros distintos. Cloud Control expone en su lugar un conjunto uniforme de operaciones sobre los tipos de recurso del registro de CloudFormation, así que una herramienta nueva soporta servicios nuevos sin cambios.

Es la base sobre la que se apoyan varios proveedores de Terraform y Pulumi para cubrir servicios recién lanzados.
