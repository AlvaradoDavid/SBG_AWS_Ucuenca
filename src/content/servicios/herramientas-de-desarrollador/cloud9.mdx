## Descripción

Cloud9 abre un editor con terminal sobre una instancia EC2 de tu cuenta, con la CLI de AWS lista y credenciales temporales. Durante años fue la manera estándar de nivelar el punto de partida de un taller.

Su sucesor natural para el uso rápido es AWS CloudShell, que no requiere instancia propia.

**Nota:** AWS ya no acepta clientes nuevos en este servicio. Para un taller nuevo conviene usar AWS CloudShell o un entorno local con la CLI.
