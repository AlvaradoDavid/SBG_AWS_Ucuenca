## Descripción

CodeCommit aloja repositorios Git estándar, con cifrado y control de acceso mediante políticas de IAM en lugar de un sistema de permisos aparte. Se integra directamente con CodePipeline para disparar despliegues.

Su ventaja siempre fue de gobierno, no de funcionalidad: no compite con las plataformas de colaboración públicas.

**Nota:** AWS ya no acepta clientes nuevos en este servicio. Los repositorios existentes siguen operativos.
