## Descripción

Cada SDK resuelve lo aburrido y crítico: firmar las peticiones, reintentar con retroceso exponencial, paginar resultados y obtener credenciales de la cadena de proveedores. Boto3 en Python y el SDK de JavaScript son los más usados.

La regla práctica es no llamar nunca a la API de AWS con un cliente HTTP propio: el SDK ya trae resuelto lo que se rompe en producción.
