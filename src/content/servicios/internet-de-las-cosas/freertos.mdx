## Descripción

FreeRTOS aporta el planificador de tareas y las bibliotecas de conectividad — TLS, MQTT, actualización de firmware por aire — necesarias para que un microcontrolador hable con IoT Core de forma segura.

Es software libre bajo licencia MIT: se puede usar en cualquier hardware y sin ninguna obligación de utilizar AWS.
