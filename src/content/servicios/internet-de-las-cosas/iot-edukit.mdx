## Descripción

EduKit combinaba un dispositivo basado en ESP32 con una serie de tutoriales progresivos que iban de encender una pantalla a publicar telemetría en IoT Core con certificados propios.

Para un club universitario, su estructura sigue sirviendo de guion aunque el kit ya no se distribuya.

**Nota:** AWS descontinuó el programa. El mismo recorrido se puede reproducir con hardware ESP32 genérico y FreeRTOS.
