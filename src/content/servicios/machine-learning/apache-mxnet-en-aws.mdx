## Descripción

MXNet destacaba por su eficiencia de memoria y su escalado en varias GPU, y fue durante un tiempo el marco preferido por AWS en su documentación y sus servicios.

El proyecto pasó al archivo de la Apache Software Foundation, es decir, ya no tiene desarrollo activo, aunque el código sigue disponible.

**Nota:** El proyecto está retirado en la Apache Software Foundation y no recibe desarrollo activo.
