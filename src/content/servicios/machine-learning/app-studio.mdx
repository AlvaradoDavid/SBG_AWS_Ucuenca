## Descripción

Se describe en palabras qué debe hacer la aplicación y App Studio genera la interfaz, el modelo de datos y los flujos de trabajo, conectándose a fuentes de datos existentes en AWS o en aplicaciones de terceros.

El resultado es una aplicación administrada por AWS: útil para herramientas internas, no para un producto de cara al público.
