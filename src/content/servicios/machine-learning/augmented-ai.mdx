## Descripción

Se define un umbral de confianza: por encima, la predicción del modelo se aplica sola; por debajo, el caso entra en una cola de revisión humana con una interfaz de trabajo, y la decisión de la persona se registra.

Esas revisiones sirven además como datos etiquetados para reentrenar el modelo, así que el sistema mejora con el uso.
