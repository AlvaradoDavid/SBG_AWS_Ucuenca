## Descripción

Comprehend detecta idioma, entidades, frases clave y sentimiento, y permite entrenar clasificadores propios con ejemplos etiquetados. Su variante médica extrae información clínica de textos de historia clínica.

Es un buen primer paso antes de plantear un modelo propio: si la API resuelve el caso, el proyecto se acorta en meses.
