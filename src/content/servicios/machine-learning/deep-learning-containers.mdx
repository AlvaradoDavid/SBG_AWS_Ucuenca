## Descripción

Son el equivalente de las Deep Learning AMIs para quien trabaja con contenedores: imágenes mantenidas por AWS, con las bibliotecas afinadas para su hardware y publicadas en ECR.

Se usan tal cual o como imagen base de un Dockerfile propio, lo que evita reconstruir el entorno de GPU en cada proyecto.
