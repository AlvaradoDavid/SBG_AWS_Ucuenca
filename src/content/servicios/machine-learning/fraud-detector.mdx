## Descripción

Se cargan eventos históricos etiquetados y el servicio entrena un modelo específico para ese caso, que después se combina con reglas de negocio explícitas para decidir si aprobar, revisar o rechazar cada operación.

Evita construir desde cero un sistema antifraude, que exige tanto datos como experiencia difícil de acumular.
