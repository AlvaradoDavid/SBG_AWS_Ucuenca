## Descripción

Se definen intenciones y los datos que hay que recabar para cada una, y Lex se encarga del reconocimiento de voz, la comprensión del lenguaje y la gestión del diálogo, invocando funciones Lambda para consultar sistemas propios.

Se integra directamente con Amazon Connect, que es el escenario donde más se usa.
