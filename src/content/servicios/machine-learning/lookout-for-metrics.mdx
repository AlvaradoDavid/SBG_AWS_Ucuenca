## Descripción

Lookout for Metrics vigilaba indicadores como ingresos o tasa de conversión y avisaba de desviaciones inesperadas, agrupando las anomalías relacionadas para señalar dónde estaba el origen.

Se documenta por completitud del catálogo.

**Nota:** AWS terminó el soporte de este servicio el 10 de octubre de 2025.
