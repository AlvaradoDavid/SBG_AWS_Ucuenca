## Descripción

La familia cubre distintos tamaños y modalidades, desde modelos ligeros y baratos para tareas de clasificación hasta modelos multimodales que entienden imágenes y video, además de modelos de generación visual.

Se invocan con la misma API de Bedrock que el resto de modelos, así que cambiar de proveedor es una decisión de una línea de configuración.
