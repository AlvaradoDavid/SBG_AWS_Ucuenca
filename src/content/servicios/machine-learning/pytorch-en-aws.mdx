## Descripción

No es un servicio en sí, sino el soporte de primera clase para PyTorch: imágenes de contenedor y AMI optimizadas, contenedores de entrenamiento distribuido en SageMaker AI y compilación para Inferentia y Trainium.

El código es PyTorch estándar y sigue siendo portable; lo que aporta AWS es el entorno afinado para su hardware.
