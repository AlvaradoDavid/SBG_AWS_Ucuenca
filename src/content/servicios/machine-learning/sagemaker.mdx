## Descripción

Bajo este nombre AWS agrupa hoy el catálogo de datos, los cuadernos, el procesamiento con Spark, las consultas SQL y las herramientas de aprendizaje automático en una experiencia común, con gobierno de permisos compartido.

Conviene no confundirlo con Amazon SageMaker AI, que es la parte específica de construcción, entrenamiento y despliegue de modelos.
