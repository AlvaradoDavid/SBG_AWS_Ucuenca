## Descripción

Cloud Map mantiene un directorio de recursos con nombres lógicos — `pagos.produccion` — que resuelven a la dirección actual de contenedores, funciones o colas, con verificación de estado para no devolver instancias caídas.

ECS lo usa por debajo para el descubrimiento entre servicios, así que muchas veces se utiliza sin haberlo configurado a mano.
