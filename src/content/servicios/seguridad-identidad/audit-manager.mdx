## Descripción

Audit Manager toma un marco normativo, lo traduce a controles concretos y recoge automáticamente la evidencia desde CloudTrail, Config y Security Hub, dejándola lista para el auditor.

No garantiza el cumplimiento: reúne y ordena las pruebas. La interpretación y las brechas siguen siendo trabajo humano.
