## Descripción

El servicio ofrece un Active Directory real operado por AWS, con parches y réplicas resueltos, o un conector que reenvía las peticiones al directorio local sin copiar las credenciales a la nube.

Es la pieza que permite que WorkSpaces, RDS para SQL Server o FSx for Windows funcionen con el inicio de sesión corporativo de siempre.
