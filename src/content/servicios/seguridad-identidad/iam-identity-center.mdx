## Descripción

Identity Center — antes AWS SSO — centraliza a las personas y los conjuntos de permisos que se les asignan en cada cuenta. Cada acceso entrega credenciales temporales, así que no hay claves de larga duración circulando por computadoras portátiles.

Es la recomendación actual de AWS para el acceso humano; los usuarios de IAM con clave permanente quedan para casos excepcionales.
