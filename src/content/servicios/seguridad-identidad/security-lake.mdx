## Descripción

Security Lake normaliza todo al esquema abierto OCSF y lo deja en S3 particionado, listo para consultarse con Athena, OpenSearch o la herramienta que prefiera el equipo. Se acaba el trabajo de unificar formatos distintos de cada origen.

Es la base sobre la que se construye un análisis de seguridad propio en vez de depender solo de paneles cerrados.
