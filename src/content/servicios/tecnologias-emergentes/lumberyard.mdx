## Descripción

Lumberyard ofrecía un motor 3D completo con código fuente disponible, integración directa con los servicios de AWS para el lado servidor y con las funciones de Twitch para transmisión.

Amazon donó el motor a la Linux Foundation, donde continúa como Open 3D Engine bajo gobernanza abierta.

**Nota:** El producto dejó de ofrecerse bajo este nombre; su continuación es el proyecto de código abierto Open 3D Engine.
