## Descripción

El servicio opera los nodos, la red y el mecanismo de consenso de una red privada de Hyperledger Fabric, y también ofrece acceso administrado a nodos de redes públicas como Ethereum o Bitcoin.

La pregunta previa siempre es si el problema necesita realmente una cadena de bloques: si existe una parte de confianza aceptada por todos, una base de datos sale mucho más barata.
